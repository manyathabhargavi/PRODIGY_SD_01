About this project

TEMPORA

Smart Temperature Conversion Suite

Tempora is a multi-page web application that converts a temperature value and its original unit into the other two supported units — Celsius, Fahrenheit, and Kelvin. It was built to demonstrate a complete, working front-end application: input validation, instant conversion, persistent history, and a responsive, accessible interface, without relying on any framework.
